# Генератор резюме (ATS Resume Builder)

Клиентское веб-приложение для составления аккуратных, структурированных и ATS-совместимых резюме с адаптацией под конкретную вакансию. Результат доступен для скачивания в форматах **DOCX (Microsoft Word)** и **PDF** с полной поддержкой кириллицы.

## Ключевые возможности

- **100% приватность:** Все вычисления и генерация файлов происходят в браузере. Данные сохраняются исключительно в `localStorage` пользователя и никогда не отправляются на сторонние серверы.
- **Пошаговый мастер (5 шагов):**
  1. *Вакансия:* Ввод требований и локальное NLP-извлечение ключевых навыков.
  2. *Личные данные:* Контакты, формат работы, фото и раздел «О себе».
  3. *Образование:* ВУЗы, специальности, степени и курсы.
  4. *Опыт работы:* Места работы, буллеты достижений и интерактивная подсветка совпадений с вакансией. Чекбокс «Нет опыта».
  5. *Навыки и доп.:* Теги навыков, языки (A1–C2), доп. секции и виджет оценки процента соответствия вакансии.
- **3 ATS-шаблона:**
  - *Классический:* Строгая одноколоночная структура, высокая проходимость парсеров.
  - *Современный:* Элегантные цветные акценты и бейджи.
  - *Минималистичный:* Лаконичный дизайн с тонкой сеткой и легкими отступами.
- **Экспорт в DOCX и PDF:** Именование файлов по стандарту `Резюме_ФИО_Должность`.
- **Поддержка языков:** Переключатель языка резюме **RU / EN**.
- **Темы оформления:** Светлая и тёмная темы.

## Запуск проекта

### Требования
- Node.js 18+ (рекомендуется LTS 20+)
- npm

### Установка зависимостей
```bash
npm install
```

### Запуск сервера разработки
```bash
npm run dev
```
Откройте браузер по адресу: [http://localhost:3000](http://localhost:3000)

### Проверка сборки и линтинга
```bash
npm run build
npm run lint
```

## Как добавить новый шаблон оформления

1. **Создайте компонент интерактивного превью:**
   - В директории `src/components/Preview/templates/` создайте файл с новым шаблоном, например `CreativeTemplate.tsx`.
   - Примените стилизацию на базе переданного `props: { data: ResumeData }`.
   - Подключите компонент в `src/components/Preview/ResumePreview.tsx`.

2. **Добавьте стиль в генератор DOCX:**
   - Откройте `src/lib/generateDocx.ts`.
   - Добавьте условия для нового шаблона (выбор шрифта, цвета заголовков, стиль разделителей).

3. **Добавьте стиль в PDF-генератор:**
   - Откройте `src/components/pdf/ResumePdf.tsx`.
   - Добавьте правила стилей в `createPdfStyles` для нового идентификатора шаблона.

4. **Зарегистрируйте шаблон в селекторе и схеме данных:**
   - В `src/lib/schema.ts` добавьте идентификатор в `template: z.enum([...])`.
   - В `src/components/Preview/ControlPanel.tsx` добавьте кнопку нового шаблона в список вариантов.
